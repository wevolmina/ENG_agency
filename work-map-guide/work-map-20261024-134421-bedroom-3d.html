C: 별도 checkout에서 구현했고 D: 드라이브 재연결 뒤 기존 변경 목록을 확인해 보존했습니다. 게시 원본은 위 소스 SHA입니다.

개발 환경의 재검증 방법

루트에서 공개 Firebase 웹 설정을 준비해 개발 서버를 실행합니다. Playwright가 설치된 Windows 환경에서 아래 검사를 실행합니다. 다른 모듈 위치는 PLAYWRIGHT_MODULE_PATH, 다른 주소는 UI_BASE_URL로 지정합니다.

npm run dev --workspace @bridge/customer
node tests/browser/bedroom-3d.cjs
node tests/browser/commerce-motion.cjs

3D 검사는 렌더링과 구매 화면 전달까지입니다. 실제 주문 생성은 별도 운영 검증입니다. commerce-motion은 가상 인증·주문 응답으로 UI 회귀를 검사합니다.
