# 계정 승인 표시와 간편로그인 점검 결과

기준일: 2026-10-25 한국 시간.

## 현재 상태

|항목|결과|
|---|---|
|네이버|고객·판매자·관리자 버튼을 `display:none`으로 숨기고 세 사이트 자동 배포 완료. 고객의 로그인 배치를 두 열로 조정. 서버 설정은 보존|
|판매자 구글|Firebase 실제 승인 목록에 판매자 주소 추가 완료. 구글 인증 및 판매자 대시보드·주문 조회 성공 확인|
|카카오|사용자가 Vercel 시크릿을 수정하고 재배포한 뒤 고객 사이트 실제 로그인 성공. ‘간편로그인 계정으로 로그인했습니다’와 로그아웃 버튼 확인|
|계정 승인 표시|일반 계정은 ‘내 계정 / 이용 권한 안내’. 서버에서 마스터 또는 최초 등록 대상으로 확인한 계정만 승인 제목·관리 메뉴 표시|

## 구글 원인과 조치

처음에는 운영 Firebase 승인 도메인에 고객의 두 Firebase 주소와 관리자 Cloudflare 주소만 있었다. 저장소 firebase.json에 판매자 주소가 있어도 실제 운영 목록에는 반영되지 않았으며 `auth/unauthorized-domain`이 발생했다.

사용자 승인 후 `paybridge-mock.vercel.app`을 실제 목록에 저장했다. 구글 계정 선택과 휴대전화 본인 인증 후 판매자 매출·주문 화면까지 확인했다. 운영 주문을 새로 만들거나 권한을 추가하지 않았다.

## 카카오 원인과 해결 확인

동의 화면과 계정 인증은 통과했으나 공식 오류 `KOE010`을 확인했다. 카카오 문서에서 클라이언트 시크릿 누락 또는 불일치에 해당한다.

사용자가 Vercel `KAKAO_CLIENT_SECRET`을 직접 수정·저장하고 재배포했다고 알렸다. 이후 새 카카오 로그인 요청으로 기존 승인 범위인 서비스 회원번호 제공 동의를 진행했다. 고객 사이트에 ‘내 계정’, ‘간편로그인 계정으로 로그인했습니다’, ‘로그아웃’이 표시되어 실제 로그인 완료를 확인했다. 이전 `SOCIAL_KAKAO_KOE010`은 이번 요청에서 재발하지 않았다.

Vercel은 소스 커밋 `eb1e0065eeb569c647e74c8d342acfd7c65e95be`의 배포 [G6qe16SdBVRfAbEFZ8LGbRoqdvvY](https://vercel.com/wevolmina94-9986/paybridge-mock/G6qe16SdBVRfAbEFZ8LGbRoqdvvY)를 성공으로 보고했다. 비밀값을 에이전트가 읽거나 입력하지 않았으며 채팅·보고서·소스에 기록하지 않는다.

세 사이트는 같은 Vercel 로그인 서버를 사용하므로 이 서버의 올바른 시크릿이 필요하다. 로그인 후 돌아올 주소는 `https://paybridge-mock.vercel.app/api/auth/social/callback/kakao`다.

## 계정과 권한

로그인 성공과 판매자·관리자 승인은 별개다. 간편로그인으로 생성된 계정에 직원 역할을 자동 부여하지 않는다. 로그인 후 고유번호를 마스터에게 전달하고 역할 승인을 받는다. 별도 신청 대기함은 없다.

이번 운영 카카오 검증은 고객 사이트에서 수행했다. 판매자·관리자 카카오 로그인과 권한별 화면은 실제 계정으로 추가 검증하지 않았다. 판매자 구글 세션은 유지했으며 새 주문이나 역할을 생성하지 않았다.

서버의 마스터 UID·온라인 구글 신원·활성 관리자 소속 검사는 유지한다. 일반 관리자도 다른 계정을 조회·승인할 수 없다. 실제 다른 사용자 계정으로 모든 권한 조합을 확인했다는 의미는 아니다.

## 코드와 검증

[PR #8](https://github.com/wevolmina/paybridge-mock/pull/8)은 승인 표시와 안전한 진단 코드를 수정했다. [PR #9](https://github.com/wevolmina/paybridge-mock/pull/9)는 네이버 숨김, 키·시크릿 주변 공백 정리, 고정된 공식 KOE 코드 구분을 반영했다. 제공업체 설명 원문·인증 코드·토큰은 반환하지 않는다.

단위 검사 73개, 세 앱 CI 빌드, 소셜로그인 브라우저 검사가 통과했다. 세 사이트에서 네이버가 실제 `display:none`이고 접근 가능한 버튼 목록에서 제외되는지 검사했다. 운영 고객·관리자 화면에서도 숨김을 확인했다. 소스 커밋과 배포 실행은 [verification.json](verification.json)에 기록한다.

## 근거

- [카카오 공식 오류 문서](https://developers.kakao.com/docs/ko/kakaologin/trouble-shooting): KOE010은 클라이언트 시크릿 누락·불일치.
- 운영 Firebase Console 승인 도메인 목록과 판매자 브라우저 로그인 완료 화면.
- 운영 카카오의 이전 `SOCIAL_KAKAO_KOE010` 진단 화면과 재배포 후 고객 사이트 로그인 완료 화면. 실제 비밀값이나 계정 이메일은 기록하지 않는다.
