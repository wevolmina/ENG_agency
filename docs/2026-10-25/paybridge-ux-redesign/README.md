## 화면별 변경

|화면|변경 내용|

|공통|로그인 시 비활성 업무 메뉴 제거. 글자 크기·간격·버튼 조정. 선택 메뉴 표시, 제목으로 키보드 초점 이동, 짧은 상태 모션과 움직임 줄이기 유지|

## 검증 범위

로컬 브라우저의 인증·권한·주문 응답은 시험 자료로 대체한다. 실제 운영 계정 등록·권한 변경·주문 생성은 하지 않는다. 실제 간편로그인 공급자 인증을 완료한 것으로 표시하지 않는다.

새 화면 검사는 첫 화면 제목 위치, 데스크톱 로그인 버튼 노출, 역할별 메뉴 분리, 계정별 역할 묶음과 가림, 주문 검색, 320/390/768/1440px 가로 넘침, 움직임 줄이기, 브라우저 오류를 확인한다. 기존 승인·해제·보안·소셜로그인·주문·모션 검사도 실행한다.

## 주요 파일

- `apps/customer/src/CartStore.tsx`, `storefront.css`: 고객 첫 화면과 선택적 계정 영역.
- `packages/staff-ui/StaffDashboard.tsx`, `workspace.css`: 역할별 로그인·메뉴·업무 배치.
- `packages/staff-ui/StaffAccess.tsx`: UID별 계정 카드와 역할 묶음.
- `tests/browser/role-workspaces.cjs`: 새 사용 흐름과 화면 구조 검사.

기존 상태와 요청을 메뉴 이동만으로 초기화하지 않도록 비활성 영역은 숨겨 유지한다. 메뉴 분리는 서버 접근 권한을 대신하지 않으며 기존 권한 검사는 그대로 사용한다. 신청 대기함, 신규 가입 신청, 서버 기간 검색, 다중 상점 기능을 추가하지 않았다.

고객 Firebase / 판매자 기존 Vercel / 관리자 Cloudflare 주소를 유지한다. 배포 완료 여부는 검증 기록과 실제 배포 상태를 확인한 뒤 기록한다.

## 로컬 검증 결과

단위 검사 67개, 세 앱 빌드, 브라우저 검사 6종이 통과했다. 데스크톱·모바일 그림을 직접 확인했다. 상세 항목과 배포 상태는 [verification.json](verification.json)에 기록한다.
