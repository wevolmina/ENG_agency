01 / CUSTOMER

고객 페이지 · 체험하고 함께 고르기

공간을 둘러본 뒤 필요한 구성을 한 주문에 모으는 화면입니다.

고객 사이트 열기

공간 체험

침실에서는 조명, 밝기, 휴식·독서 분위기, 보는 각도를 바꿉니다. 주방에서는 사람 들어오기·수납장 문 열기를 눌러 가상 조명 반응을 봅니다. 입체 화면이 열리지 않으면 가벼운 그림으로 바꿀 수 있습니다.

묶음 선택

침실·주방·데스크 패키지를 각 1개씩, 최대 3종 고릅니다. 선택 수와 구성·합계가 함께 바뀝니다. 데스크는 입체 체험 대신 그림의 가상 집중 모드를 제공합니다.

모의 주문과 복구

구성·합계를 확인하고 직접 동의한 뒤 모의 주문을 보냅니다. 구성을 바꾸면 동의를 다시 받습니다. 결과를 놓쳤다면 같은 주문 결과를 다시 확인하고, 이전 영수증을 복원할 때 완료 동작을 반복하지 않습니다.

필요한 순간의 움직임

선택한 구성은 짧게 나타나고, 모의 승인 결과를 받은 뒤에만 완료 표시가 나옵니다. 공간 바로가기와 선택 없음 안내를 추가했습니다. 기기의 ‘움직임 줄이기’ 설정도 따릅니다.

내가 할 일
  1. 고객 사이트의 침실 체험 또는 주방 체험을 엽니다.
  2. 패키지를 선택하고 가상 조명·센서 반응을 봅니다.
  3. 스토어로 돌아와 선택한 구성과 합계를 확인합니다.
끝났는지 확인

선택 수·구성·합계가 맞고, 화면을 나갔다 돌아와도 선택을 이어갈 수 있어야 합니다. 모의 결제까지 시험할 때는 주문이 저장된다는 점을 먼저 확인하세요.

02 / SELLER

판매자 페이지 · 주문과 모의 매출 확인

고객이 완료한 주문을 판매자의 관점에서 보는 화면입니다.

판매자 사이트 열기

구성과 합계 확인

누적 모의 매출과 주문 건수, 주문별 구성·수량·금액을 봅니다. 세 패키지를 함께 산 주문도 각 구성을 표시합니다. 매출은 실제 정산 금액이 아닙니다.

새 주문만 한 번 강조

보이는 화면에서 약 5초 간격으로 확인합니다. 처음 불러온 주문이나 같은 응답에는 알림을 반복하지 않습니다. 새 주문의 행과 매출만 짧게 강조하고, 화면을 숨기면 확인 작업을 잠시 멈춥니다.

최근 내역 검색

최근 100건 안에서 패키지명·주문 번호·결제 번호로 찾습니다. 위쪽 누적 금액은 전체 기간 기준이므로 검색 결과의 합계와 범위가 다를 수 있습니다.

역할에 맞는 로그인

이메일·비밀번호로 로그인한 뒤 판매자 권한을 확인합니다. 로그인 성공만으로 매출을 볼 권한이 생기지는 않습니다. 연결이 늦으면 이전 값을 유지하고 자동으로 다시 확인합니다.

내가 할 일
  1. 판매자 사이트에서 승인된 기존 계정으로 로그인합니다.
  2. 주문·결제 내역에서 확인할 주문을 찾습니다.
  3. 고객 영수증과 같은 주문인지, 구성과 합계가 맞는지 비교합니다.
끝났는지 확인

새 주문 1건을 한 번만 새 주문으로 알려야 합니다. 이 동작은 시험용 자료로 확인했습니다. 이번 운영 배포 뒤의 실제 계정 조회는 별도 확인이 남았습니다.

관리자 페이지 · 별도 주소에서 관리

판매자와 함께 있던 접속 경로를 Cloudflare 관리자 사이트로 분리했습니다.

관리자 사이트 열기

주소와 로그인 상태 분리

관리자는 별도 주소로 접속합니다. 기존 판매자 사이트의 관리자 경로는 새 주소로 이동합니다. 같은 계정을 쓰더라도 두 사이트의 로그인·로그아웃 상태는 따로 유지됩니다. 고객 메뉴에서는 관리자 진입을 뺐습니다.

공간 그림 카드와 필터

긴 목록을 침실·주방·데스크 그림 카드로 바꿨습니다. 전체 / 스토어 공개 / 구매 중지로 나눠 보고, 공개된 개수를 확인합니다. 저장 중인 대상만 결과 확인 중으로 표시합니다.

바뀐 공개 상태만 안내

관리자에게 일반 새 주문 알림을 띄우지 않고 조용히 갱신합니다. 패키지 공개 상태가 바뀌면 새 변경 이력만 한 번 강조합니다. 변경 전·후 상태와 시각을 타임라인으로 구분합니다.

키보드와 연결 보호

필터에서 카드가 사라지면 선택된 필터로 키보드 초점을 돌립니다. 서버는 매 요청에서 로그인과 관리자 권한을 확인합니다. 정해진 관리자 주소의 연결만 허용하도록 설정했습니다.

지원 범위를 꼭 구분하세요. 세 패키지 카드가 보여도 공개 상태를 바꾸는 기능은 현재 침실 패키지만 지원합니다. 주방·데스크 공개 변경, 계정 권한 편집, 승인·정산·취소·환불 업무는 이번 작업으로 완성한 기능이 아닙니다.

내가 할 일
  1. Cloudflare 관리자 주소를 엽니다.
  2. 기존 관리자 계정으로 로그인하고 공개 상태 필터를 봅니다.
  3. 상태 변경 시험은 침실 패키지에서, 어떤 상태로 바꿀지 정한 뒤 진행합니다.
  4. 저장 결과와 변경 이력을 함께 확인합니다.
아직 모르는 것 / 확인하는 방법

새 주소의 화면 게시와 연결 보호는 확인했습니다. 실제 관리자 계정의 자료 조회·상태 변경은 아직 시험하지 않았습니다. 다음 확인 하나는 기존 관리자 계정으로 로그인하여 목록을 읽기만 하는 것입니다.

앞으로 바뀌는 점

검토한 변경을 main에 합치면 해당 화면이 자동 배포됩니다. main은 정식으로 게시할 코드를 모으는 기준 줄기입니다. 세 배포는 각각 실행되므로 결과도 따로 봅니다.

고객·관리자는 관련 파일이 바뀔 때 배포합니다. 문서만 바꾸면 두 사이트를 다시 게시하지 않습니다.

이제 당장 다시 설정할 것은 없습니다. 사이트가 게시됐다는 사실과 실제 계정에서 모든 기능이 동작한다는 사실은 다릅니다. 남은 일은 계정별 기능 확인입니다.
