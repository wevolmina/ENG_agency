# 배포 안내서가 자동 배포 기준으로 변경되었습니다

[페이브릿지 자동 배포 안내서](AUTO_DEPLOYMENT.md)를 확인하세요.

Firebase·Cloudflare는 GitHub Actions, Vercel은 Git 연동으로 main 변경을 배포합니다. 기존 수동 배포 설명은 최초 연결·관리자 주소 확보와 장애 복구에만 사용합니다. 새 안내서에 GitHub Variables 4개·Secrets 2개, 최초 준비, PR 병합과 결과 확인을 정리했습니다.

처음 한 번 계정·배포 권한을 연결해야 하며, 문서와 설정 파일 반영 자체가 운영 자동 배포 완료를 의미하지는 않습니다.
