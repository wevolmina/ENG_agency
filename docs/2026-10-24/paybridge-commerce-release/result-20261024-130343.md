## 실제 확인

- 구매자 침실 선택→모의 동의→완료, 동일 요청 재시도·새로고침 복원.
- 기존 계정 실제 로그인 후 판매자와 관리자 모두 두 주문 번호·198,000원 확인.
- 타인 영수증404, 일반 구매자 직원API403.
- 관리자가 임시 비공개로 바꾼 뒤 catalog 제외·기존 영수증/동일 checkout 재시도 확인, 다시 공개 복구.
- 운영 새 주문1건 강조·기준 조회/반복 조회는 알림 없음.

일반 테스트19 통과. 격리 MySQL 경합/롤백/비공개 복구 통합 통과. Java21 Firestore 규칙 공격 입력 시험 통과. 양쪽 빌드 통과. 로컬 UI fixture의 응답 유실/늦은 복원/focus/390px/reduced-motion 통과. 실제 운영 두 주문과 UI fixture는 별개 증거다. CPU6배 모사 시험은 실제 저사양 FPS/INP 측정이 아니다.
